RDD PARCEIRO BMB3 - V2 OCR

Substitua os arquivos da raiz do repositório GitHub por:
- index.html
- manifest.webmanifest
- sw.js
- config.js

Esta versão recupera a etapa de carregamento dos cupons no próprio navegador:
- câmera/galeria
- seleção de vários arquivos
- JPG/JPEG/PNG
- tentativa de conversão HEIC/HEIF
- OCR no navegador com Tesseract.js
- identificação automática de data, documento, descrição e valor
- lupa
- edição manual
- categoria obrigatória
- documento obrigatório
- rascunho local
- geração bloqueada enquanto faltarem dados obrigatórios

O botão GERAR RDD + CUPONS ainda deixa os dados prontos para a API; a integração Excel/PDF será ligada depois que o frontend estiver validado no GitHub Pages.
